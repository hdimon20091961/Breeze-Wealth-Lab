# Market Breeze для Wealth-Lab 8

**Market Breeze 0.11.33** — расширение Wealth-Lab 8 для совместного анализа широты
рынка, индекса S&P 500, фьючерсной кривой VIX и девяти торговых ансамблей:
трёх TorchSharp4GPU, четырёх TorchSharp/Jordan и двух Encog. В TorchSharp4GPU
ZZ1 является осцилляторным направлением, ZZ2 — трендовым, а ZZ3 использует ATR.
Все графики используют общий диапазон дат, курсор и навигацию.

Репозиторий содержит полный воспроизводимый комплект исходников расширения,
исследовательских стратегий Wealth-Lab, встроенных каталогов, Help,
проверочных проектов и готовых файлов выпуска. Локальные рыночные истории,
нейросетевые модели и большие видео не публикуются. Проект рассчитан на
Windows x64, Wealth-Lab 8 и дневные данные.

## Возможности

- **Rules1 / Rules2** — взаимоисключающий выбор расчётной модели, две
  одновременные полосы оценок и подробная карточка выбранного профиля.
  Rules1 сохраняет текущую 75-признаковую модель; Rules2 отображается на своей
  нормированной шкале 0–100 с исходными правилами входа/выхода.
  [Руководство переключения Rules](docs/market-breeze-rules-switch.md).
- **Сворачиваемые панели** — каждый из четырёх графиков Trading Ensemble
  сворачивается до строки заголовка; размеры, выбранная модель и профиль
  сохраняются между открытиями.
- **Fuzzy map** — состояние рынка, итоговая оценка модели, целевая позиция,
  основные положительные и отрицательные факторы, EMA, ATRP, широта, Titanic,
  Zweig и состояние кривой VIX.
- **Trading Ensemble** — фактические линии прежних TorchSharp4GPU ZZ1/ZZ2/ZZ3,
  TorchSharp ZZ1/ZZ2, Jordan ZZ1/ZZ2 и Encog ZZ1/ZZ2, а также сценарный Forecast. Отображаются центральный сценарий и варианты изменения цены
  на ±1% и ±2%. Нижняя панель показывает `Active Deciles` и их процент, а
  выключенный по умолчанию флажок `Ensembles` переключает её на
  `Active Ensembles` со шкалой 0–9 и процентом от девяти систем. Режим
  Scoring classification отключён и удалён из интерфейса.
- **All breadths** — доли компонентов S&P 500 и Nasdaq-100 выше выбранных
  скользящих средних, совместно или отдельными панелями.
- **Contango** — скорректированная структура фьючерсов VIX с разными допусками
  для front и хвоста, накопленной инверсией, spot/ценовым стрессом и
  подтверждением переходов. На SVXY-графике доступны диагностические полосы
  `New` и `Old`; остальные графики и модели используют только `New`.
- **Titanic** — условия SentimenTrader Titanic, New High/New Low и длительность
  активной серии.
- **Zweig** — Breadth Thrust в фиксированных исследованных режимах Strong и
  Working.
- **Sentiment** — синхронные SPY и нормализованные индикаторы настроения;
  ARSI использует период 14, а MyRSI 14,8 доступен отдельной серией.
- **Market Setup** — крайняя правая вкладка с полным каталогом 149 записей из
  `BreezeEventCatalog.json`: 86 вычисляемых детекторов из `BreezeRules.json` и
  исследовательские конструкции с определениями, статусом и сохранёнными
  результатами. Исследовательская запись без детектора DLL не получает
  выдуманного значения или веса. Выбранное исполняемое правило отображает
  вычисленное состояние на SPY, автоматически включает необходимые EMA/MyRSI,
  а нижняя панель показывает только отмеченные индикаторы.
  Доступны обе MyRSI_rep(14,8)/(10,8) + AGC(77), Aroon, DI и корреляционные
  индикаторы; Jocker и Market Breadth используют параметры ZZ1/ZZ2.
  Русские пояснения показывают условия на дате курсора; T02 различает
  частичный рост EMA и рост всех четырёх, U01 выделяет этапы повторного отрыва.
  Колонки сжимаются до чекбоксов и кодов правил, описание можно полностью
  свернуть. После EMA доступны четыре выключенных по умолчанию ряда широты:
  S&P SMA50/100/200 и Nasdaq SMA100. На нижнем графике широты используют
  независимую правую шкалу процентов, индикаторы — левую.
  Фильтр «Активные» рядом с «Правила» оставляет правила с ненулевым весом
  хотя бы в одном профиле Soft/Standard/Hard; по умолчанию показаны все.
  Значения трёх весов расположены вверху описания без строки номера и типа.
  ATRP(1) расположен последним после Nasdaq в блоке широт и имеет отдельную
  синхронную панель. Выбор T03 включает EMA, четыре широты и ATRP с ориентиром 2%.
  Включены медвежьи зеркала T01/T02/T03, подтверждённые T03/1 и шесть отдельных
  T04. Новые детекторы имеют датированные значения и пояснения; исходный
  75-признаковый скоринг и его веса сохранены.
  Пустые нижние панели полностью скрываются: только EMA — один график SPY,
  выбранные индикаторы/широты и ATRP показывают нужные панели. Автоматические
  слои и ручные дополнения предыдущего правила снимаются. После изменения
  раскладки шкалы обновляются по текущему общему диапазону дат.

Шкалы зависят от типа панели; принятые значения и исключения описаны в
[стандарте форм](docs/ui-standards.md). Колесо мыши изменяет количество видимых баров с шагом 20,
перетаскивание двигает общий временной диапазон, а двойной щелчок фиксирует
курсор. Навигация синхронна между вкладками и панелями.

## Forecast

Параметр **Forecast** задаёт число исторических точек, для которых выполняется
сценарный расчёт; значение по умолчанию — 10, шаг изменения — 5. При значении
0 расчёт отключён.

Для следующего расчётного дня используются известные значения признаков,
которые невозможно спрогнозировать: значение последнего реального дня
переносится на T+1. Это не означает прогноз самого внешнего признака. На
графике будущая область отделена от последней реальной свечи и не изображается
как обычный торговый бар.

Все девять ансамблей можно показывать по отдельности или одновременно. Цветовые
границы и пунктирные сценарные линии дают диапазон возможного движения, а не
гарантированное значение будущей цены.

## Сохранение интерфейса

Breeze запоминает положение всех перемещаемых границ панелей, включая сетку
Full на вкладке All breadths и обе границы Market Setup. Настройки
сохраняются после перетаскивания и восстанавливаются при следующем запуске:

```text
%APPDATA%\WealthLab8\BreezeLayout.json
```

Файл создаётся автоматически. Удаление файла возвращает стандартную раскладку.

## Установка

1. Соберите оба проекта командами из следующего раздела.
2. Закройте Wealth-Lab 8.
3. Скопируйте из каталогов сборки в папку Wealth-Lab:
   `Breeze.dll`, `Breeze.Strategies.dll`, `BreezeHelp.html`,
   `BreezeRules.json`, `BreezeEventCatalog.json` и
   `Indicators.JohnEhlers_8Wealth.dll`.
4. По умолчанию папка установки имеет адрес:
   `C:\Program Files\Quantacula, LLC\WealthLab 8`.
5. Запустите Wealth-Lab и откройте **Market Breeze**.

Для автоматической установки собранного комплекта можно запустить
`deploy-to-wealthlab.ps1` с правами администратора. Сценарий создаёт резервную
копию и проверяет контрольные суммы источника и установленных файлов. Другую
папку Wealth-Lab можно передать параметром `-WealthLabDirectory`.

### Реплики индикаторов John Ehlers

В `release` включена требуемая сборкой библиотека
`Indicators.JohnEhlers_8Wealth.dll` для Wealth-Lab 8. Она предоставляет
реплики индикаторов, в том числе классы с суффиксом `_rep`, используемые при
построении признаков (`MyRSI_rep`, `CorrelationAngle_rep` и связанные
преобразования). Штатные библиотеки Wealth-Lab в выпуск не дублируются.

Полный перечень самостоятельных стратегий, способы их проверки и необходимые

## Данные и рабочие каталоги

Репозиторий не содержит рыночную историю, модели TorchSharp и библиотеки
Wealth-Lab. Текущая конфигурация использует:

```text
D:\fear_greed_close\VIX                 история фьючерсов VIX
D:\fear_greed_close\Breeze              расчётные CSV Breeze
D:\fear_greed_close\vix_term_structure.csv
D:\TorchSharp4GPU                        модели и данные торговых ансамблей
```

S&P 500, Nasdaq-100, SPY, SVXY и внутренние индикаторы загружаются через
выбранные динамические DataSet Wealth-Lab. При открытии расширения основной
расчёт запускается автоматически; кнопка **Recalculate** выполняет его повторно.

## Сборка и проверка

Требуются .NET 8 SDK, Windows x64 и установленный Wealth-Lab 8. Сборка не
распространяет библиотеки Wealth-Lab и использует локальные DLL из его папки.

```powershell
dotnet build .\Breeze\Breeze.csproj -c Release -p:Platform=x64
dotnet build .\Breeze.Strategies\Breeze.Strategies.csproj -c Release
```

Основные интеграционные проверки:

```powershell
dotnet run --project .\tests\Fuzzy\Breeze.FuzzySmokeTest.csproj -c Release
dotnet run --project .\tests\EventModel\Breeze.EventModel.SmokeTest.csproj -c Release
dotnet run --project .\tests\Contango\Breeze.ContangoSmokeTest.csproj -c Release -- "D:\fear_greed_close\VIX"
dotnet run --project .\tests\MarketSetup\Breeze.MarketSetupSmokeTest.csproj -c Release
dotnet run --project .\tests\RulesSwitch\RulesSwitch.csproj -c Release
dotnet run --project .\tests\RulesSwitchUI\RulesSwitchUI.csproj -c Release -- "D:\CODEX_PRG\Breadth"
```

Проверка модели на срезе 23.10.2026 включает 75 признаков и 664 037 контрольных
сравнений; Contango-тест обрабатывает 4 652 файла дневной истории. Числа зависят
от среза входных данных. Полный каталог содержит 141 запись; принятую
исследовательскую модель 77/34 нельзя отождествлять с рабочими профилями 75/32.

## Важно

Breeze является исследовательским и визуальным инструментом. Forecast,
состояния рынка и расчёт позиции не являются гарантией результата или
индивидуальной инвестиционной рекомендацией.
