# Принятая модель: Standard + G01/Decibel + PH01/Hurst–CMF

25.10.2026. По прямому указанию пользователя лучшая проверенная добавка PH01/Hurst–CMF включена поверх ранее принятой Standard + G01/Decibel. Годовые веса перенесены из завершённого опыта без новой оптимизации. Прежняя версия сохранена отдельно.

## Сколько правил

| Что считаем | Количество |
|---|---:|
| Все записи общего каталога: события, варианты, представление признака и исполнение | 105 |
| Правила, выбранные для расчётной модели, включая нулевые | 77 |
| Из них с ненулевыми настроенными весами | **34** |
| Исходные правила Standard с ненулевым весом | 32 |
| Принятые добавки с ненулевыми весами: G01 и PH01 | 2 |
| Исходные правила, оставленные с весом 0 | 43 |
| Прочие исследовательские записи вне расчёта | 28 |

Все восемь уточнений «Подхват1» PH01–PH06/PX01–PX02 включены в реестр этой версии. PH01 участвует в оценке; остальные сохраняются с нулевым вкладом и результатами проверки. Неуспешным или недостаточно подтверждённым вариантам не назначены произвольные веса. Это не удаление конструкций из исследования.

Здесь считается каждый ID один раз. Четыре состояния Hurst–CMF не являются четырьмя отдельными событиями. Ненулевой настроенный вес не означает ненулевой вклад каждый день: нужен активный детектор, а годовая таблица может отключать добавку. Статистическую значимость число 34 не обозначает.

Исторических запусков именно PH01 — 83 на доступном интервале расчётной базы, из них 60 в 2020–2026 годах. 37 карточек видеозаписи и 105 записей каталога — другие единицы учёта.

## Как добавляется PH01

`Score = clip(PreviousAcceptedScore + PH01 × Weight[year,HurstState,CMFState], 0, 100)`.

Исходная Standard и G01/Decibel сохраняются. PH01 — последовательность «устойчивый рост → сохранённый контекст → коррекция → первый зелёный ответ с растущей B50 и удержанной EMA50». Точные условия, память, отмены и кадры находятся в [спецификации опыта](D:/CODEX_PRG/Breadth/research/artifacts/podhvat_candidate_experiment_v1/specification.md) и [восьми уточнениях](D:/CODEX_PRG/Breadth/research/artifacts/podhvat_video_revision_v1/heuristics.md).

Hurst и CMF сравниваются каждый со своей медианой **предыдущих 252 баров**, без текущего бара. Равенство относится к нижнему состоянию. Неизвестное состояние даёт нулевую добавку. Состояние определяется на текущую дату решения; не фиксируется задним числом по будущему движению.

| Год | Hurst низкий / CMF низкий | Hurst низкий / CMF высокий | Hurst высокий / CMF низкий | Hurst высокий / CMF высокий |
|---|---:|---:|---:|---:|
| 2020 | 0 | 0 | −20 | −2.5 |
| 2021 | 0 | 0 | −20 | −2.5 |
| 2022–2025 | 0 | 0 | 0 | 0 |
| 2026 и продолжение | +10 | +10 | −20 | −2.5 |

До 2020 года PH01 не меняет предыдущую принятую оценку. После 2026 года сохраняются последние принятые веса до отдельного решения; автоматического переобучения нет. Отрицательные веса здесь намеренные: не каждый ранний подхват означает увеличение позиции.

## Воспроизведённый результат

| Интервал | Прибыль прежней модели, $ | Прибыль новой, $ | Прибавка к прибыли | MaxDD прежняя → новая |
|---|---:|---:|---:|---:|
| 02.01.2020–23.10.2026 | 6354.61 | 6639.87 | +285.26 / **+4.49%** | 12.799% → 12.799% |
| 26.10.2015–23.10.2026 | 7730.42 | 8015.68 | +285.26 / **+3.69%** | 8.871% → 8.871% |

В окне 2020–2026 доходность к начальному капиталу 3000 меняется с 211.820% до 221.329%, то есть на **9.509 процентного пункта**. Это отличается от относительного прироста прибыли +4.49%. Изменён 21 день фактической позиции. Прибавка сосредоточена в 2026 году (+315.78$); 2020 даёт −30.52$, остальные годы примерно ноль.

Исполнение прежнее: 10 SPY при оценке ≥50, иначе 0; решение после закрытия, сделка на следующем открытии, 2 базисных пункта на сторону, капитал 3000, без ограничения по наличным. В отдельном прогоне с началом в 2020 году возможен отрицательный остаток денег. Лимитные политики PX01/PX02 не добавлены к исполнению, и их результаты не суммируются с прибавкой PH01.

Лучший ряд выбран после сопоставления 42 исторических вариантов. Внутри ряда годовые веса обучались только на предшествующей истории с отступом 126 баров, однако выбор лучшего ряда не является нетронутой внешней проверкой. Все остальные результаты, включая отрицательные, сохранены в [отчёте опыта](D:/CODEX_PRG/Breadth/research/artifacts/podhvat_candidate_experiment_v1/README.md).

## Проверка и область применения

[Сборщик](D:/CODEX_PRG/Breadth/research/models/standard_plus_g01_decibel_ph01_hurst_cmf_v1/build_model.py) заново вычисляет детекторы и состояния, применяет сохранённые веса, сверяет каждую тестовую дату с проверенным рядом и прибыль/просадку/издержки с обоими окнами отчёта. Он также сверяет исходные веса с живым BreezeRules.json и проверяет неизменность прежней модели, исходных CSV, рабочих исходников и правил по SHA-256. Указатели текущей модели и каталога обновляются после этих проверок.

Это принятая **исследовательская расчётная модель** для последующих сравнений, как и предыдущая версия. Её числовой ряд и полный состав сохранены. Рабочая DLL не пересобиралась и не развёртывалась; в рабочем BreezeRules.json остаются 75 исходных правил, 32 с ненулевым Standard-весом. Исследовательские 77/34 нельзя выдавать за уже развёрнутые 75/32.
