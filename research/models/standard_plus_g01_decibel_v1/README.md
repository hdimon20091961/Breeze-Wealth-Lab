# Принятая база: Standard + G01/Decibel

25.10.2026 пользователь принял дополнение к базовому скорингу.
Эта составная модель зафиксирована как текущая база последующих исследований
в `research/models/current_model.json`.

Исходные75 событий, их веса и предыдущий снимок Standard сохранены.
Добавляется только испытанный G01 с состоянием Decibel и фактически выбранными
в опыте годовыми весами. До2020 добавка равна0. С2026 и для продолжения:
−20 при Decibel≤медианы предыдущих252 баров, +10 выше медианы.
Самостоятельная перенастройка в эту принятую версию не включена.

`accepted_model.json` содержит точную композицию, расписание и контрольные суммы;
`accepted_score.csv` — ежедневные исходная оценка, добавка, составная оценка и цели.
`build_model.py` воспроизводит пакет и сверяет его с испытанной ветвью.

Это зафиксированная исследовательская модель. Рабочая DLL и установленные файлы
Wealth-Lab в рамках этой фиксации не заменены. Следующее исследование широт
сравнивается с этой составной базой и отдельно с первоначальной Standard.
