# Исследовательские стратегии Market Breeze

В репозитории сохранены самостоятельные исходники Wealth-Lab, использованные
для проверки торговых режимов и сопоставления с расчётами Market Breeze.
Исходники можно открывать, исследовать, изменять и повторно компилировать.

| Исходник | Назначение |
|---|---|
| `Проторговка_TorchSharp_Rules.cs` | Проторговка Rules 1/Rules 2 по точным торговым датам SPY. |
| `проторговка_на_TorchSharp_вариантNL.cs` | Базовая проторговка пакетов TorchSharp/Encog. |
| `проторговка_на_TorchSharp_вариантNL_Futures.cs` | Вариант проторговки с фьючерсными признаками. |
| `проторговка_состояний_EMA_MyRSI.cs` | Исследование состояний EMA и MyRSI с позицией до 10 лотов. |
| `ген_на_TorchSharp_oll_indi_ансамбльGPT_mult_(что если люстра).cs` | Полная генерация признаков и ансамблей, режимы позиции и сценарий «что если люстра». |
| `Rules2ResearchStrategy.cs` | Исследовательский движок и параметры Rules2. |

XML `release/Проторговка Torch Sharp_Rules.xml` можно импортировать непосредственно
в Wealth-Lab. Исходный код стратегии внутри XML соответствует отдельному файлу
`Проторговка_TorchSharp_Rules.cs`.

## Индикаторы John Ehlers

Библиотека `release/Indicators.JohnEhlers_8Wealth.dll` содержит реплики
индикаторов John Ehlers для Wealth-Lab 8, включая используемые стратегиями
классы с суффиксом `_rep`. Это отдельная прикладная зависимость выпуска;
штатные DLL Wealth-Lab в репозиторий не копируются.

## Проверка компиляции

Для проектов требуется установленный Wealth-Lab 8. Библиотеку реплик
`Indicators.JohnEhlers_8Wealth.dll` следует скопировать из `release` в папку
Wealth-Lab либо установить вместе со всем выпуском.

```powershell
dotnet build .\tests\RulesFuturesCompile\RulesFuturesCompile.csproj -c Release
dotnet build .\tests\EnsembleStrategyCompile\EnsembleStrategyCompile.csproj -c Release
```

Первый проект компилирует проторговку Rules, второй — генератор ансамблей с
люстрой. Основные проекты расширения собираются командами из корневого README.

## Внешние рабочие данные

Исходники стратегий содержат параметры и алгоритмы, но не публикуют рыночные
истории и обученные модели. Для полного исполнения используются локальные
каталоги моделей TorchSharp/TorchSharp4GPU/Encog и данные, перечисленные в
корневом README. Это отделяет воспроизводимый код от изменяемых и крупных
рабочих данных.
