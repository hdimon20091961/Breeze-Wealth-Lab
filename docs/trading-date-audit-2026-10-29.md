# Аудит торговых дат — 2026-10-29

## Единое правило

Историческая дата допускается в расчёт Market Breeze только тогда, когда WealthData вернул фактический дневной бар SPY на эту дату. Проверка по дню недели или отдельному списку праздников не заменяет фактический ряд SPY.

Для присоединяемых рядов действует строгое совпадение даты. Ближайшее предыдущее или следующее значение нельзя использовать для VIX curve, spot VIX, торгового состояния или подтверждения перехода.

## Найденный дефект

`VixTermStructureStore` индексировал все файлы `VIX\yyyy-MM-dd.csv`, включая биржевые праздники, и подбирал ближайший spot VIX. Например, файл 2026-01-19 повторял фьючерсные цены 2026-01-16 с уменьшенным DTE, но получил spot VIX 2026-01-20. Искусственный разрыв 20,74% изменил состояние 2026-01-19 и задержал повышение 2026-01-20.

## Исправленные потребители

- Contango New/Old и SVXY: только пересечение точных файлов VIX curve с фактическими датами SPY.
- Spot VIX: только точное совпадение даты; при отсутствии значения spot-поправка не применяется.
- Двухсессионное подтверждение: только последовательные фактические сессии SPY; пропуск точного VIX-файла разрывает последовательность.
- `vix_term_structure.csv`: только фактические даты SPY.
- `contango_market_state.csv`: только фактические даты SPY.
- `vix_term_structure_rules2.csv`: только даты, принятые центральным Contango New; roll-флаг пересчитывается между соседними фактическими сессиями.
- График VIX curve: требует точный файл выбранной торговой даты, ближайший файл больше не подставляется.
- Zweig и Titanic: выходные точки дополнительно ограничены множеством фактических дат SPY.

## Уже корректные компоненты

- Fuzzy map, технические индикаторы и Sentiment используют даты дневных баров SPY как ведущий ряд.
- Market Setup и Rules1 строятся по строкам SPY и присоединяют остальные признаки по точной дате.
- Rules2 перечисляет строки `SPY.csv` и читает VIX/EMA/широту через точный ключ даты.
- Стратегии Wealth-Lab применяют рассчитанные значения только к точным датам баров торгуемого инструмента.
- Методы `FindNearestIndex` в классах графиков выбирают ближайшую нарисованную точку только для движения курсора и не участвуют в расчёте данных.

## Отдельные будущие даты

Прогноз Trading Ensemble для ещё не наступившего следующего бара не является историческим состоянием и помечен `IsNextBar`. Для всех исторических прогнозов дата берётся из следующего фактического бара. Календарные предупреждения об экспирации используют загруженные даты SPY для прошлого; расчёт календаря применяется только к будущему, когда фактического бара ещё не существует.
