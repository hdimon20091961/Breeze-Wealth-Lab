# Breeze 0.10.1

Версия управления синхронизированными графиками поверх позиционной модели
0.10.0.

- при нажатии левой кнопки в области вкладок указатель временно становится
  горизонтальными стрелками `SizeWE`;
- двойной щелчок на текущей вертикальной линии фиксирует общую дату;
- зафиксированная линия становится синей и утолщённой на всех графиках;
- движение мыши после фиксации больше не меняет дату и левое описание;
- следующий одиночный щелчок по графику снимает фиксацию;
- колесо в любой точке левой панели `Market state at cursor` прокручивает текст
  и не масштабирует график;
- колесо масштабирует общий временной диапазон только над графиком;
- кнопки, флажки, ползунки и списки внутри вкладок сохраняют обычное поведение.

Сборка и Help проверены вместе с расчётом 74-событийной модели.
