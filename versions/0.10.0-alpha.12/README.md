# Breeze Hold Position_new — 0.10.0-alpha.12

Совместная оптимизация ненулевых весов автономной стратегии Wealth-Lab.

- `BreezeHoldPositionStrategy_new.cs` — полный исходник для вставки в C#-редактор Wealth-Lab.
- Breeze.dll и прежние версии не изменяются.
- Engine закреплён как Level; базовый Level равен 50.
- По умолчанию установлен экономичный сбалансированный набор: Profit 234.51%, Max Drawdown -10.45%, Recovery Factor 10.69, Position Count 1460.
- В оптимизатор одновременно выведены все 35 ненулевых весов.
- Каждый активный вес получает локальные градации `current-5 / current / current+5`; для веса `+5` диапазон `0..10`, для `-5` диапазон `-10..0`.
- Остальные 39 признаков остаются в каталоге, ежедневно рассчитываются и имеют фиксированный вес 0.
- Полный перебор `3^35` невозможен. Используйте ограниченный не исчерпывающий поиск с заранее заданным числом испытаний.

Ненулевые веса: T03, T05, T06, T07, T08, T09, E01, E02, E03, E05, E06, R01, R02, R03, R05, B01, B02, B03, B07, B08, B09, P02, P03, P05, V01, V03, V04, V07, V08, Z02, Z03, I01, C01, C05, C08.
