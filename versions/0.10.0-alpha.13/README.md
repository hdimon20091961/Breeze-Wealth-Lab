# Breeze Hold Position_new — 0.10.0-alpha.13

Эталонная автономная стратегия Wealth-Lab после выборочной совместной оптимизации и пользовательского форматирования факторной таблицы.

- `BreezeHoldPositionStrategy_new.cs` — полный исходник для вставки в C#-редактор Wealth-Lab.
- `Breeze.Strategies.New.dll` — собранная отдельная библиотека стратегии; это не `Breeze.dll`.
- `Breeze.dll` и прежняя стратегия не изменялись.
- Первый параметр выбирает замороженный профиль: `0=Soft`, `1=Standard`, `2=Strong`.
- Второй параметр включает однофакторный стресс-тест профиля Strong и выводит в Debug Log таблицу `BASE / MAX / MIN`.
- `Standard` — выбранная пользователем кривая: Profit 251.19%, Max Drawdown -9.41%, Sharpe 1.607, Recovery 10.872, Position Count 1400.
- `Strong` — максимум доходности пяти выборочных прогонов: Profit 251.51%, Max Drawdown -9.37%, Sharpe 1.611, Recovery 10.886, Position Count 1380.
- `Soft` — кандидат с наименьшей просадкой при Profit выше 240%: Profit 248.03%, Max Drawdown -9.16%, Sharpe 1.620, Recovery 10.343, Position Count 1380.
- В факторном тесте проверяются только ненулевые веса Strong: исходный вес, 0 и удвоенный вес. Торговля и три профиля в тесте не переоптимизируются.
- Все 74 события продолжают рассчитываться; нулевые веса не удалены из модели.

Формат Debug Log в этой версии принят как пользовательский эталон: фиксированные колонки, общий Strong BASE, затем отдельные блоки каждого фактора с разделителями.
