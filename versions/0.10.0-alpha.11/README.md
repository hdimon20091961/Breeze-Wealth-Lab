# Breeze Hold Position_new — 0.10.0-alpha.11

Третья и последняя прогонка оставшихся событий автономной стратегии Wealth-Lab.

- `BreezeHoldPositionStrategy_new.cs` — полный исходник для вставки в C#-редактор Wealth-Lab.
- Breeze.dll и прежние версии не изменяются.
- Engine закреплён как Level; Level следует зафиксировать на 50.
- Зафиксирован чемпион alpha.10: Profit 236.51%, Max Drawdown -10.51%, WLScore 20.82.
- Новые закреплённые веса: V03=-5, V07=-5, Z03=10, Z04=-10, C01=10.
- Нейтральные или вредные параметры второй группы оставлены равными нулю.
- Проверяются E07, P06, C02, C03, C07, C10, C11, C12, U01, U02.
- Для каждого параметра сетка содержит ноль и одну рабочую альтернативу.
- Точный набор чемпиона присутствует в сетке. Полная сетка при Level=50 — 1024 комбинации.
- U01 на текущей истории не срабатывает и служит контролем полноты каталога.
