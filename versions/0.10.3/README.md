# Breeze 0.10.3

Настройка компоновки первой вкладки Fuzzy map.

- `Market state at cursor` и `Model: [Soft/Standard/Strong]` находятся в одной
  строке;
- список модели закреплён в правом верхнем углу левой панели;
- между левой информационной панелью и правым графиком добавлен коричневый
  вертикальный разделитель шириной 5 пикселей;
- разделитель можно тянуть влево и вправо, меняя ширину обоих окон;
- установлены минимальные ширины 285 и 320 пикселей, чтобы содержимое не
  схлопывалось;
- выбранное соотношение ширины сохраняется и восстанавливается через настройки
  рабочего пространства.

Навигация, колесо ±25 бар, синяя фиксация и позиционная модель не изменялись.
