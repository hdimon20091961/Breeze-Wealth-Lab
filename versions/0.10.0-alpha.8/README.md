# Breeze Hold Position_new — 0.10.0-alpha.8

Первая из трёх заключительных прогонок оставшихся событий автономной стратегии Wealth-Lab.

- `BreezeHoldPositionStrategy_new.cs` — полный исходник для вставки в C#-редактор Wealth-Lab.
- Breeze.dll и прежние версии не изменяются.
- Engine закреплён как Level; для этой прогонки Level следует зафиксировать на 50.
- Зафиксирован выбранный результат alpha.7: Profit 217.21%, Max Drawdown -11.15%, WLScore 19.23.
- Проверяются 11 параметров: T07, T10, R02, R06, R07, B05, B10, B11, B13, P01, V02.
- Каждый параметр имеет две ненулевые градации; полная сетка при Level=50 — 2048 комбинаций.
- После этой прогонки останется 21 ещё не проверенный параметр, разделённый на два последующих набора: 11 и 10.
