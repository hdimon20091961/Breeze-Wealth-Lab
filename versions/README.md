## Current archive policy

The list above is a historical inventory, not a current total. Later preserved
directories include 0.10.21–0.10.25 and 0.10.27–0.10.32; gaps must not be filled
with invented binaries. Versions 0.10.31/0.10.32 contain five runtime files, their release
README and SHA256SUMS. `tools/publish_release.ps1` creates a new version directory
and refuses to overwrite an existing historical version. Old directories and
partial snapshots are retained as they were; completeness differs by version.

Version 0.10.33 adds the approved ATRP pane to Market Setup. It retains the
original scoring formulas and weights. The independent EMA/HLC3 experiment is
stored under `research/artifacts/ema_t01_t04_experiment_v1`, including all trials
and frozen inputs; it is not a new accepted scoring model.

Version 0.10.34 enables eleven additional EMA display detectors in Rules,
Market Setup, chart/cursor and Help. Catalogue v7 contains 141 entries with
unchanged permanent numbers for the preceding 130. Runtime display has 86
detectors; the frozen scoring vector retains its original 75 features/weights.

Version 0.10.35 fixes empty Market Setup panes and stale rule dependencies,
preserving manual selections and refreshing scales after the adaptive layout.
