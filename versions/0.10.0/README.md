# Breeze 0.10.0

Первая библиотечная версия новой позиционной событийной модели, перенесённой
из автономной стратегии Wealth-Lab `BreezeHoldPositionStrategy_new` alpha.13.

- один общий код расчёта 74 состояний в стратегии и DLL;
- профили Soft, Standard и Strong, по умолчанию Standard;
- непрерывный Score 0–100 для цветной полосы;
- итоговое исполнение по исследованному фиксированному уровню 50:
  ниже уровня 0/10 контрактов, на уровне и выше 10/10;
- новое наполнение `MODEL POSITION` и `Market state at cursor` с главным
  положительным/отрицательным вкладом и активными событиями;
- Help содержит полный каталог 74 состояний, включая сохранённые нулевые веса,
  точные действующие формулы и таблицу чувствительности Strong по убыванию
  максимального абсолютного изменения ProfitPct;
- `BreezeHelp.generated.html` — полностью развёрнутый Help для чтения вне
  Wealth-Lab;
- `validation.json` — результат проверки общей событийной модели.

Сборка: `Breeze.dll`, версия файла и сборки `0.10.0.0`.
