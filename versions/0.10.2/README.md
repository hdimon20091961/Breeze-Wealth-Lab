# Breeze 0.10.2

Исправление маршрутизации колеса и компоновки выбора позиционной модели.

- колесо над любым правым временным графиком снова изменяет общий диапазон
  ровно на 25 бар;
- масштабирование работает и при зафиксированной синей вертикальной линии;
- только конкретная левая панель `Market state at cursor` перехватывает колесо
  для вертикальной прокрутки текста;
- ошибочная общая проверка служебных `ScrollViewer` шаблона вкладок удалена;
- выбор `Model: Soft/Standard/Strong` перенесён из верхней легенды в левое окно;
- заголовок и выбор модели размещены в две строки, чтобы не пересекаться при
  узкой ширине панели.

Позиционная модель и её веса не изменялись.
